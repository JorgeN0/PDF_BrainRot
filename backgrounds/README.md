# Background clips

Drop your gameplay videos here (`.mp4`, `.webm`, `.mov`, `.mkv`). Each file shows up in the
website's background picker, named after the file: `minecraft_parkour.mp4` becomes
"Minecraft Parkour".

- Any aspect ratio works. Clips are center-cropped to 9:16.
- Longer clips are better. Each video starts at a random point, and a clip shorter than the
  narration just loops.
- The clip's own audio is muted.

The clips aren't included in the repo, and everything in this folder except this README is
gitignored. Use footage you recorded yourself or have the rights to use.
